## Overview

**Eveee** is an EV (Electric Vehicle) charging station discovery, booking, and management platform. Users can browse charging stations on a map or list view, view station details (connectors, pricing, ratings), and book charging slots. The app uses a custom Express.js backend with PostgreSQL and Drizzle ORM.

## Data Flow

1. **Authentication**: `useAuth` → Express backend → JWT session stored in localStorage and React context
2. **Station Discovery**: `useStations` → React Query → Express backend `stations` + `chargers` tables → Map/List display
3. **Booking**: `BookingForm` → `useCreateBooking` → Express backend `bookings` table → Cache invalidation via React Query
4. **Profile**: Auth state change → `fetchProfile` → Express backend `users` table

## Database Schema

| Table | Purpose |
|-------|---------|
| `stations` | EV charging station locations & metadata |
| `chargers` | Connector types/power per station |
| `bookings` | User charging slot reservations |
| `users` | User profile data |
| `reviews` | Station reviews by users |

### Enums
- `booking_status`: pending, confirmed, active, completed, cancelled, expired
- `charger_status`: available, occupied, reserved, out_of_service, maintenance

## Conventions

- **Naming**: PascalCase for components, camelCase for hooks (prefixed with `use`), kebab-case for UI primitives
- **Structure**: Feature-based component organization (booking, map, stations, layout, ui)
- **State**: React Context for auth, React Query for server state, local state for UI
- **Styling**: TailwindCSS + custom glass-morphism classes (`glass-card`, `glass-button`)
- **Routing**: React Router v6 with flat route structure
- **Animation**: Framer Motion for page transitions and micro-interactions
