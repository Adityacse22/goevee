## Overview

**Eveee** is an EV (Electric Vehicle) charging station discovery, booking, and management platform. Users can browse charging stations on a map or list view, view station details (connectors, pricing, ratings), and book charging slots. The app uses Supabase as a BaaS for authentication, database, and row-level security.

## Data Flow

1. **Authentication**: `useAuth` → Supabase Auth → session stored in React context
2. **Station Discovery**: `useStations` → React Query → Supabase `stations` + `station_connectors` tables → Map/List display
3. **Booking**: `BookingForm` → `useCreateBooking` → Supabase `bookings` table → Cache invalidation via React Query
4. **Profile**: Auth state change → `fetchProfile` → Supabase `profiles` table
